# Assets Guide: Where to Save Your Textures & Images

I've updated the code to look for specific files in the `assets` folder. Save your files with these exact names (or update the CSS/HTML if you name them differently).

## 1. Textures (Backgrounds)
**Location:** `assets/textures/`

| File Name | Purpose | Recommended Style |
| :--- | :--- | :--- |
| `desk-bg.jpg` | Main background behind the stack | Dark wood, marble, or a cute patterned tablecloth |
| `paper-texture.png` | The background for the documents | Crumbled paper, parchment, or subtle noise (transparent or light cream) |
| `polaroid-texture.png` | Optional overlay for photos | Dust/scratches or a glossy paper effect |

## 2. Stamps & Decorations
**Location:** `assets/stamps/`
*Note: These should ideally be transparent PNGs.*

| File Name | Purpose |
| :--- | :--- |
| `stamp-confidential.png` | "CONFIDENTIAL" stamp on Cover |
| `stamp-approved.png` | "CASE CLOSED" stamp on Final Page |
| `coffee-stain.png` | A coffee ring stain (optional decoration) |
| `washi-tape.png` | Tape graphics for holding things down |
| `paper-clip.png` | Realistic paper clip image (replaces the CSS border one) |

## 3. Photos (Polaroids & Evidence)
**Location:** `assets/images/`

| File Name | Purpose |
| :--- | :--- |
| `photo-cover.jpg` | Use for the Cover page profile picture or main photo |
| `photo-evidence-1.jpg` | Evidence Page: Photo 1 (e.g., "Cute smile") |
| `photo-evidence-2.jpg` | Evidence Page: Photo 2 (e.g., "Crime scene") |
| `photo-us.jpg` | Plea Page: Photo of the two of you |

---

**Tip:** If your images are excessively large (like 4K photos), try to resize them to around 1000px wide so the page loads faster!
