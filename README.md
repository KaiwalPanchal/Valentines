# Valentine's Mystery Game 💌

## What is this?

So... I made this cute little interactive thing to ask someone out. Yeah, I know—programmers gonna program, even when it comes to romance.

This is basically a digital scrapbook/mystery game that opens up like a folder with pages you can flip through. It's got some personal memories, inside jokes, and eventually leads to the big question. Very smooth, very subtle. 😅

## The Story Behind This

I'm not a design nerd. Like, at all. I changed my mind about 5 times before settling on this version. There were other ideas—some involving way too many animations, one that was basically a visual novel, another that was just... let's not talk about that one.

But hey, this is what I landed on, and honestly? I'm pretty happy with how it turned out. It's got:
- A 3D folder that opens (because why not)
- Pages you can flip through with memories and stuff
- Some decorative elements that make it feel handmade
- Mobile support (because she's definitely gonna open this on her phone)

## Tech Stack

- Vanilla HTML/CSS/JavaScript (keeping it simple)
- No frameworks (because sometimes you don't need React for everything)
- A lot of CSS transforms and animations
- Some questionable design choices that somehow work

## Running It

Just open `index.html` in a browser. That's it. No build process, no npm install, no webpack config. Old school.
